# TextAnalyzer — Анализ текста и работа с Set
## Функционал

- **Удаление дубликатов** — автоматическая фильтрация повторяющихся слов
- **Сохранение порядка** — слова выводятся в порядке первого появления (`LinkedHashSet`)
- **Сортировка** — алфавитный вывод уникальных слов (`TreeSet`)
- **Нормализация** — приведение к нижнему регистру и очистка от знаков препинания
- **Статистика** — подсчёт общего количества уникальных слов
